# YouTube Agent Skill — نسخه‌ی فارسی

۱۱ تا اسکیل رایگان Claude که کارای یه کانال یوتیوب رو برات انجام می‌دن: از ایده و اسکریپت تا عنوان، تامبنیل،
ادیت، کامنت و تحلیل آنالیتیکس. این نسخه برای فارسی‌زبان‌ها بومی شده.

- **سازنده‌ی اصلی:** Jake Schincariol — github.com/Jakeschincariol/youtube-agent-skill (لایسنس MIT)
- **نسخه‌ی فارسی:** MSA — Motion Studio Art (اینستاگرام: @motionstudioart)

> این اسکیل‌ها **چیزی منتشر نمی‌کنن.** متن، برنامه و لیست کات تحویلت می‌دن؛ آپلود و انتشار با خودته.
> هیچ عدد و نتیجه‌ای هم از خودشون نمی‌سازن؛ اگه عددی لازم باشه، ازت می‌پرسن.

## ۱۱ اسکیل

| دستور | چی کار می‌کنه |
| --- | --- |
| `/yt-script` | یه ایده رو اسکریپت می‌کنه: ۵ تا هوک از ۲۱ فرمول، امتیازدهی‌شده، بعد متن کامل با بیت‌های نگه‌داشتن بیننده |
| `/yt-package` | عنوان و تامبنیل رو با هم چک می‌کنه: طول، تکرار، کلی‌گویی |
| `/yt-edit` | از روی زیرنویس، لیست کات با تایم‌کد می‌ده: سکوت‌ها، «اِ، خب، یعنی»، جمله‌هایی که از اول گفتی |
| `/yt-comment` | کامنت‌ها رو تو ۴ دسته می‌چینه و با لحن خودت جواب می‌نویسه؛ می‌گه کدوم رو پین کنی |
| `/yt-plan` | برنامه‌ی هفته به اندازه‌ی وقتی که واقعاً داری: یه ویدیوی اصلی، یه ویدیوی سبک، سه تا Shorts |
| `/yt-viral` | ویدیوهایی که تو حوزه‌ی تو ترکوندن رو پیدا می‌کنه، بر اساس اینکه چند برابرِ میانگین کانال خودشون دیده شدن |
| `/yt-retention` | فایل ریتنشن یوتیوب رو می‌خونه و می‌گه بیننده دقیقاً کجا رفت و اون لحظه چی می‌گفتی |
| `/yt-shorts` | Shortsهایی که توی یه ویدیوی بلند قایم شدن رو درمیاره، با جمله‌ی اول جدید برای هر کدوم |
| `/yt-seo` | توضیحات، تگ‌های به‌دردبخور و سه تا جستجویی که این ویدیو باید ببره |
| `/yt-chapters` | چپتر از روی زیرنویس، طبق قوانین خود یوتیوب |
| `/yt-audit` | کل کانالت رو بررسی می‌کنه و آخرش **فقط یه** اصلاح پیشنهاد می‌ده، نه بیست تا |

## نصب

### الف) Claude Code (ویندوز، مک، لینوکس)

۱. پوشه‌ی `skills` رو از این زیپ باز کن.
۲. همه‌ی پوشه‌های `yt-*` رو کپی کن تو:
   - **ویندوز:** `C:\Users\<اسم‌کاربری>\.claude\skills\`
   - **مک و لینوکس:** `~/.claude/skills/`
۳. Claude Code رو دوباره باز کن و بنویس: `/yt-script`

یا راحت‌تر: زیپ رو کنار Claude Code بذار و بهش بگو:
«این زیپ رو باز کن و پوشه‌های yt-* رو تو اسکیل‌های من نصب کن، بعد چک کن /yt-script کار می‌کنه.»

### ب) سایت claude.ai (بدون Claude Code)

۱. تو پوشه‌ی `claude-ai` برای هر اسکیل یه زیپ جدا هست (مثلاً `yt-script.zip`).
۲. تو claude.ai برو به **Settings → Capabilities**، بخش **Skills**، و زیپ هر اسکیلی که می‌خوای رو آپلود کن.
۳. اگه بخش Skills رو نمی‌بینی، اول گزینه‌ی اجرای کد (Code execution) رو تو همون صفحه روشن کن.

ابزارهای پایتونی (امتیاز هوک، لیست کات و…) روی claude.ai تو محیط خود Claude اجرا می‌شن.

### پیش‌نیاز ابزارها

شش تا ابزار پایتونی دارن (`hookscore.py`، `title.py`، `deadair.py`، `chapters.py`، `retention.py`، `swipe.py`).
فقط Python 3 لازمه؛ هیچ کتابخونه‌ی اضافه‌ای نمی‌خوان و به اینترنت وصل نمی‌شن. روی ویندوز با `python` اجرا کن،
نه `python3`.

## قدم اول بعد از نصب: پروفایل صدات

فایل `templates/voice_fa.md` رو کپی کن به `~/.claude/youtube/voice.md` (ویندوز:
`C:\Users\<اسم‌کاربری>\.claude\youtube\voice.md`) و پرش کن. یا سه تا از ویدیوهای خودت رو به Claude بده و بگو:
«از روی اینا voice.md منو بنویس.» همه‌ی اسکیل‌ها این فایل رو می‌خونن، و چون متن رو باید خودت جلوی دوربین بگی،
این ده دقیقه از هر پرامپتی مهم‌تره.

## چی فارسی شده

- هر ۱۱ اسکیل جواب رو به فارسی محاوره‌ای می‌دن، نه ترجمه‌ی خشک انگلیسی. اسم ابزارها لاتین می‌مونه.
- ۲۱ فرمول هوک اسم، توضیح و مثال فارسی دارن و جمله‌ی فارسی رو تشخیص می‌دن.
- ابزارها عدد فارسی (۱۲۳)، نیم‌فاصله، «ي/ك» عربی و علامت‌های فارسی (؟ ، ؛) رو درست می‌خونن.
- لیست کات، پرکننده‌های فارسی (اِ، خب، یعنی، چیزه، دیگه…) و جمله‌هایی که از اول گفتی رو پیدا می‌کنه.
- تخمین زمان ویدیو برای فارسی با حدود ۱۱۵ کلمه در دقیقه حساب می‌شه، نه ۱۵۰.

## محدودیت‌ها (صادقانه)

- **امتیاز هوک راهنماست، نه پیش‌بینی.** روی فارسی لیست کلمه‌هاش هنوز کوتاهه؛ هیچ هوکی رو فقط به‌خاطر امتیاز پایین
  دور ننداز. بلند بخونش و با گوش خودت قضاوت کن.
- **عنوان چپترها خامن.** کلمه‌های موضوعی‌ان، نه جمله‌ی تو؛ قبل از گذاشتن، بازنویسی‌شون کن.
- **`/yt-viral` فقط صفحه‌های عمومی رو می‌خونه،** وارد حسابت نمی‌شه و رمز نمی‌خواد.
- برای دریافت درآمد از یوتیوب شرایط خود یوتیوب (حد نصاب سابسکرایبر و ساعت تماشا) و روش دریافت پول از ایران
  جداگانه‌ست؛ این اسکیل‌ها فقط ساختن ویدیو رو سریع‌تر و بهتر می‌کنن.
